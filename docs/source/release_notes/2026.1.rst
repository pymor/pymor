pyMOR 2026.1 (September 4, 2026)
------------------------------

We are proud to announce the release of pyMOR 2026.1!

This release includes an adaptive and randomized ERA reductor, classes for matrix-equation
solvers, an implementation of adaptive model hierarchies and energy-stable projection
for port-Hamiltonian systems.

pyMOR 2026.1 contains contributions by Maximilian Bindhak, Nicholas Lüer, Art Pelling, Timo Plath,
Johannes Rettberg, and Sven Ullmann.
See `here <https://github.com/pymor/pymor/blob/main/AUTHORS.md>`__ for more details.

Matrix Equation Solver
~~~~~~~~~~~~~~~~~~~~~~
In `[2572] <https://github.com/pymor/pymor/pull/2572>`_, we restructured the solution
of matrix-equations around a matrix-equation solver interface. Every matrix-equation
solver exposes a solve method that takes the equation to solve, represented by one of four new
matrix-equation classes: :class:`~pymor.solvers.matrix_equations.equations.LyapunovEquation`,
:class:`~pymor.algorithms.solvers.matrix_equations.equations.RiccatiEquation`,
:class:`~pymor.algorithms.solvers.matrix_equations.equations.PositiveRiccatiEquation` and
:class:`~pymor.algorithms.solvers.matrix_equations.equations.SylvesterEquation`. Since one is
typically interested either in the full dense solution or in a low-rank of it, each equation
(except :class:`~pymor.algorithms.solvers.matrix_equations.equations.SylvesterEquation`,
for which only dense solvers are available in pyMOR) comes with two solver interfaces, e.g.
:class:`~pymor.solvers.matrix_equations.interface.LyapunovSolver` for the
dense solver and :class:`~pymor.solvers.matrix_equations.interface.LyapunovSolverLR`
for the low-rank solver, resulting in a total of seven interface classes.

The previously standalone matrix-equation solver functions in :mod:`~pymor.bindings.scipy`,
:mod:`~pymor.bindings.slycot`, :mod:`~pymor.matrix_equations.equations.adi`,
:mod:`~pymor.solvers.matrix_equations.radi` and :class:`~pymor.solvers.matrix_equations.sylvester`
are now classes implementing one of these seven interfaces. In line with the equation solvers
introduced in the previous release, default solvers are provided in
:mod:`~pymor.solvers.matrix_equations.default` for each of the seven interfaces, selecting
a concrete solver based on the available bindings and the problem size.

Adaptive model hierarchy
~~~~~~~~~~~~~~~~~~~~~~~~
In `[2577] <https://github.com/pymor/pymor/pull/2577>`_, the adaptive and certified
model hierarchy introduced in :cite:`HKOSW23` is implemented in a general fashion.
When querying the model hierarchy for a new parameter, the cheapest but least accurate model
in the hierarchy is evaluated first. Its accuracy is assessed by an a posteriori error
estimator whose estimate is compared to a prescribed tolerance. If the result was accurate enough,
it is returned, otherwise the hierarchy falls back to the next model, repeating this process.
At the same time, the data of later models in the hierarchy is collected and used to train
the earlier models. The different models in the hierarchy (except for the reference model,
i.e. the final fallback option which does not require any error estimation) are thus constructed
adaptively while already querying the hierarchy. In the :doc:`tutorial <../tutorial_mor_with_ml>`
related to data-driven model reduction using machine learning, the application of the model
hierarchy combining a full order model, a reduced basis reduced order model and a machine
learning surrogate is shown in a multi-query setting.

Energy-stable projection for PHLTIModels
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
In `[#2553] <https://github.com/pymor/pymor/pull/2553>`_, we added an alternative test-space
choice to the :class:`pymor.reductors.ph.basic.PHLTIPGReductor`. Previously, the test space
was always fixed to :math:`W = QV`, which yields a reduced system that is again port-Hamiltonian.
The new energy-stable projection instead uses :math:`W = (J - R)^{-\top} E V`. In this case the
reduced system is no longer port-Hamiltonian, but the Hamiltonian is preserved, i.e.,
:math:`\tilde{H}(\tilde{x}) = H(V \tilde{x})`. The same projection was added as an option
to :class:`~pymor.reductors.ph.ph_irka.PHIRKAReductor`
:meth:`~pymor.reductors.ph.ph_irka.PHIRKAReductor.reduce` method and can be tried in the
:mod:`!phlti` demo script. This follows the energy-stable approximation of :cite:`EHS20`,
extended to the port-Hamiltonian setting as in :cite:`RWBBZFB23`.
